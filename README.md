# Airplane Tracker

Простой консольный инструмент для получения списка самолётов над выбранной страной с использованием открытых API (OpenSky и Nominatim) и сохранения результата в JSON.

## Требования

- Python >= 3.13
- pip или Poetry

Основные зависимости:

- `requests` — для HTTP‑запросов к внешним сервисам.

## Установка

### Вариант 1. Через Poetry (рекомендуется)

```bash
poetry install
```

### Вариант 2. Через pip

```bash
pip install -r requirements.txt  # если вы создадите его из pyproject.toml
```

Либо установить минимум:

```bash
pip install requests
```

## Запуск приложения

Из корня проекта:

```bash
python main.py
```

Далее:

1. Введите название страны (на любом языке, далее оно будет сопоставлено с английским названием через Nominatim).
2. Программа запросит список самолётов, относящихся к этой стране, отсортирует их по высоте.
3. Укажите максимальное количество самолётов в ответе.
4. Выбранные самолёты будут сохранены в JSON‑файл и выведены в консоль.

## Тестирование

Для проекта настроен минимальный набор тестов на `pytest`:

- `tests/test_info_jets.py` — проверка сортировки самолётов по высоте.
- `tests/test_country_coord.py` — базовый сценарий получения координат страны с замоканным HTTP‑клиентом.
- `tests/test_json_file_handler.py` — сохранение и загрузка списка самолётов в JSON.

Запуск тестов из корня проекта:

```bash
pytest
```

или, при использовании Poetry:

```bash
poetry run pytest
```
